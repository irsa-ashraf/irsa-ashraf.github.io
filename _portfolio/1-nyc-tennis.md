In this project, I built an interactive web application to help people discover public handball courts across New York City. Despite the sport’s popularity in NYC, information about court locations is often fragmented, outdated, or hard to search, especially for players looking to find courts near them or in a specific neighborhood.

This project was inspired by my own experience playing sports around the city and wanting an easy way to explore courts while moving between neighborhoods. The app allows users to search by location, visualize courts on an interactive map, and ask natural language questions through an AI assistant to quickly find nearby courts or explore options in different areas of the city.

The application combines geospatial analysis, backend APIs, and an AI agent to deliver a practical, user-facing product that bridges data and real-world use.
* Data Source: NYC Open Data
  Public handball court location data provided by NYC Open Data, including court names and geographic coordinates.
* Tech Stack:
  FastAPI, Python, geospatial distance calculations, Docker, and an AI agent built using OpenAI’s Responses API, deployed as a production-ready web application.
